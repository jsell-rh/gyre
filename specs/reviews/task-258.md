## Verified (per required behavior)

- **(1) Session-to-commit mapping.** `AgentSessionRepository` port (ports/agent_tracking.rs) implemented by SQLite (sqlite/session.rs), PostgreSQL (postgres/session.rs), and mem (MemAgentSessionRepository) with identical duplicate-id/not-exists guards; `store!` wiring into `AppState.agent_sessions` (lib.rs, mem.rs, middleware.rs test state). Sessions start at spawn (spawn_agent_core, initial branch = spawn branch) and at each Ralph-loop fresh-context respawn (ralph_loop.rs relaunch_agent_session, initial branch resolved from the worktree's real current branch). `ended_at` set on every termination path: complete_agent, fail_agent, stale-agent Dead transition, MCP `gyre_agent_complete`, and admin kill_agent (before worktree cleanup). `AgentCommit.session_id` is stamped from `find_open_by_agent` in both record_pushed_commits and POST /repos/:id/commits/record; no open session → NULL, never a fabricated id (open_session_id logs and returns None on lookup failure too). Chronological GET /repos/:id/agent-sessions/:sid/commits (find_by_session, timestamp ASC then id, all three adapters). The `two_session_attribution` integration test asserts exactly [A] in session 1 and [B] in session 2 plus a NULL-session orphan commit — it kills the fabricated-constant hollow mode.
- **(2) Branch lifecycle.** GET /repos/:id/agents/:aid/branch-lifecycle returns the first session's spawn-time branch, `current_branch` from the latest terminated session's `final_branch` (resolved at termination via real `git rev-parse --abbrev-ref HEAD`, never copied forward — test `end_session_resolves_moved_branch_not_spawn_branch` switches branches mid-session and asserts the difference), and all observed commits (agent's commits filtered to the repo, chronological).
- **(3) Dirty state.** Real `git status --porcelain` in the agent's worktree at every termination path; porcelain v1 parsing uses char-boundary-safe `line.get(3..)` and handles rename `old -> new`. Missing/inaccessible worktree records `dirty = NULL` plus `dirty_detail` — explicit unknown, never a silent clean (tested in end_session_missing_worktree_records_unknown_not_clean). Regression tests `mcp_agent_complete_terminates_open_session_with_dirty_state` and `kill_agent_terminates_open_session_before_worktree_cleanup` run against real git worktrees with uncommitted edits.
- **(4) Commit-based queries.** `files_changed` recorded per pushed commit at push time via real `git diff-tree --no-commit-id --name-only -r --root <sha>` (40-hex SHA validated before reaching the command line); stored on AgentCommit (JSON column, portable migration); GET by-file returns sessions+agents whose commits touched the path (exact match — substring and LIKE-pattern false matches impossible, tested), by-commit returns the linked session. The manual record endpoint derives the list from the repo's object store first; the caller-asserted fallback is documented and only for SHAs that live outside this forge's storage.
- **(5) Time-travel.** GET /repos/:id/agent-sessions/:sid/state: commits present during [started_at, ended_at] via real `git log --all --after/--before` against the object store (never current HEAD), plus the completion snapshot resolved from `refs/agents/{agent-id}/snapshots/{n}` (newest ref whose committer date ≤ ended_at, with tree sha and `git ls-tree -r` files). `session_state_time_travel` uses a real bare repo with pinned commit dates and asserts a post-session commit is excluded while being current HEAD.
- **Persistence/restart.** Migration `2026-11-14-000067_agent_sessions` is plain portable SQL (both backends; portability gate passes); sessions and session-stamped commits are DB rows.
- **AuthZ.** All six new routes have ABAC RouteResourceMapping entries (repo resource); handlers verify repo existence and scope session lookups to the repo path segment (cross-repo sessions are NotFound/empty, not leaked). No caller-supplied scope fields. All gates pass with no new exemptions.
