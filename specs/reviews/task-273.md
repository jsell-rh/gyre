## Non-blocking observations (follow-up, none contradict the task contract)

1. `api/oauth.rs:368-371` — enrollment defaults `expires_in` to 3600 when the provider omits it, inconsistent with the rotation handlers' honest failure on missing `expires_in`. Bounded impact (rotation normalizes or fails honestly on the next cycle).
2. `mem.rs` (`MemAuditRepository::query`/`count_filtered`) — the `q` filter runs on `event.detail` before `materialize()` decompresses, so in pure-mem mode compressed details are unmatchable by free-text search (SQL adapters decompress correctly). Mem/SQL parity wart, dev-mem-only.
3. `api/admin.rs` (kill handler, restart-orphan local arm) — kills by pid without the `/proc` start-time identity check `remote_agent_cleanup` enforces; a stale local record with a recycled pid could kill an unrelated process on an explicit admin kill. The specced cleanup job has the gate.
4. `maintenance_jobs.rs` — container/kubernetes instance kill failures retry every sweep forever (no 7-day retirement, unlike the SSH path); noise, not correctness.
5. `jobs.rs:331` — the durable-store mutex guard is held across the 3-attempt retry loop including 500 ms of sleeps (serializes recorders under a flapping store); `durable_persist_failures` counter is logs-only (not surfaced on any admin API); comment at `jobs.rs:322-330` overstates ring visibility of runs whose durable write failed.
6. Vault `create` writes data then index — a crash in between leaves a secret that resolves to agents but is undeletable by id; duplicate-existence checks are TOCTOU; `kv_list` silently drops non-string `keys` elements. All edge-case robustness.
7. No literal `sops` CLI round-trip test vector (the acceptance criterion's "spec-conformant native age decryption" branch is satisfied and tested; recommend adding a CLI-generated vector in CI to pin the MAC rule interoperably).
8. Audit `q` path pages `ORDER BY timestamp DESC LIMIT/OFFSET` without a unique tiebreaker (same-second rows can skip/duplicate across pages); SQLite `LOWER()` is ASCII-only while the Rust re-filter folds full Unicode (non-ASCII-only matches in uncompressed rows never reach the re-filter).
9. `scripts/check-tenant-filter.sh` SKIP_LIST grew three documented entries (audit.rs housekeeping reads, oauth_state.rs pre-auth capability lookup, user_profile.rs judgment ledger) — not an exemptions file, rationale inline, script passes.
