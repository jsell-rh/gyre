## Non-blocking observations (recorded for follow-up; none contradict the task contract)

- **Vault `create` is read-then-write** (no KV v2 `cas: 0` on the write): two concurrent creates of the same scope+name can both succeed, violating the port's "fails if already exists" only under that concurrency (serial enforcement is real; the task text does not require CAS). Same class: the token-refresh job's read→grant→`replace` has no compare-and-swap against a concurrent re-enrollment rewrite — lost update degrades to a loud `FAILED` + admin notification on the next cycle, never silent.
- **Test-quality nits**: `sqlite/secret.rs::tampered_ciphertext_fails_decryption` decrypts with a freshly generated identity, so its ciphertext tamper is dead weight (the MAC-tamper behavior is properly covered by `sops/mod.rs::sops_tampering_fails_mac_verification`); a few env-sensitive tests read `GYRE_SECRET_BACKEND` without `ENV_LOCK`, leaving a narrow flake window against `wrong_key_fails_decryption`'s `legacy` window (my full run passed 663/0).
- **Audit completeness (fail-closed)**: events carrying only an `agent_id` (procfs `FileAccess`/`NetworkConnect`, agent-token `AuthSuccess`) stay NULL-tenant and are invisible to tenant-scoped admin audit — matches the task's workspace-scope derivation letter; a future agent→workspace derivation step would close it.
- **Server logs are deployment-wide** (log lines may name other tenants): the spec asks only "Admin-only", which is enforced; with per-tenant admins this is a product nuance, not a defect.
- **Docs**: coverage rows 3/5/6/10 in `specs/coverage/system/admin-panel.md` cite migration numbers 000067–000070; the actual files are `2026-11-13-000071…000074` (stale pre-rebase numbering in the notes only — statuses and file paths are accurate).
- Admin-kill of a restart-orphan local instance lacks the pid-identity verification the sweep path has (asymmetry, low likelihood).
- `admin_export` still exports `activity_events` from the in-memory TelemetryBuffer (pre-existing surface, out of this task's stated scope).
