## Verified against the task contract

- **Entity fields.** `gyre-domain/src/team.rs` `Team` carries id, workspace_id, name, slug, description, lead, created_at; `TeamMembership { team_id, user_id, added_at }` is a separate entity persisted in a `team_memberships` table (composite PK) — exactly the spec's shapes. The never-writable `member_ids` JSON column is dropped by migration `2026-11-13-000062` (next unused sequence number; portable SQLite+PG SQL; up/down verified by the migration test, which asserts slug←id and lead←workspace-Owner backfills, the `(workspace_id, slug)` unique index, and the dropped column).
- **Slug URL-safety + workspace uniqueness.** `Team::validate_slug` rejects anything outside `[a-z0-9-]`, edge/consecutive `-`, >64 chars; explicit invalid slugs are 400 (never silently rewritten), omitted slugs derive from the name via `sanitize_slug` (400 when nothing URL-safe remains). Uniqueness enforced three ways: handler pre-check (409), `idx_teams_workspace_slug` unique index (race-safe backstop, mapped to a stable error label in both SQLite and PG adapters), and mem-adapter code guards with a mirroring contract test (`check-mem-port-contracts.sh` green).
- **Lead references a valid workspace member.** `validate_team_lead` checks the real `workspace_memberships` store (400 otherwise); `add_team_member` likewise rejects non-workspace-members (400) — "teams are organizational, not authorization" is enforced, not assumed.
- **CRUD endpoints work with new fields.** All four handlers now take `AuthenticatedAgent`, tenant-scope via `load_workspace_scoped`, gate on Owner/Admin/TenantAdmin (`can_manage_membership`), and 404 a team id from another workspace (previously update/delete ignored the path workspace — a real cross-workscope write fix). New `POST .../teams/:team_id/members` (duplicate → 409, response carries `added_at`) and `DELETE .../members/:user_id` (idempotent 204) are ABAC-registered (`abac_middleware.rs` + `api/mod.rs`; registry gate green).
- **Notification routing (`team:slug`).** `notifications.rs::resolve_team_members` resolves `team:{slug}` to real member ids via `find_by_slug` + `list_members`; unresolvable references log and skip — no fabricated recipients. Wired into the `SpecApprovalRequested` emitter in `save_spec`, including a real production bug fix: manifest paths (relative to `specs/`) are now normalized against the client-facing `specs/...` request path, so team routing actually matches. The test's distinguishing recipient is a Viewer — outside the Admin/Developer/Owner role fan-out — so it fails if team routing is dropped or stubbed.
- **Spec ownership (`team:slug` approvers).** `expand_team_approvers` (api/specs.rs) expands `team:{slug}` entries in `human_approvers` into the approver-id forms members' approvals record, before the pure §9 resolver runs. An unresolvable team (or an empty team) is kept verbatim: `is_valid_human_approval` requires a non-empty `human_approvers` list to contain the event's `user:...` approver id, which can never equal `team:...`, so the spec stays Pending — fail-closed, not the prior fail-open (dropping the ref emptied the list → "any human may approve"). The e2e test covers non-member-approval-stays-Pending, member-approves, and unresolvable-fails-closed arms with real git, ledger, team API, and API-key human approvals.
- **Budget reporting by team.** `GET /api/v1/workspaces/:id/budget/by-team` aggregates real `BudgetCallRecord` rows through the agent→spawning-user→teams chain, with an explicit `unattributed` bucket (nothing silently dropped); tenant-scoped in-handler; test asserts exact call/token/cost attribution including the unattributed arms.
- **Prior verification-round failures (candidate `fea1a77e9`, full `cargo test --all`): all three root causes fixed in `3056a7edd`** — (1) fail-open on unresolvable team approvers → verbatim retention (verified against resolver semantics above); (2) specs_assist routing test's git NotFound → the test helper now `git init --bare`s the recorded repo path (NoopGitOps never creates it) and passes explicit author/committer identity to `commit-tree`; (3) duplicate membership surfaced as 500 → `add_team_member` pre-checks membership and returns 409 (the adapter guard remains the race backstop).
