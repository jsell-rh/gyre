All three production `emit_tenant_event` callers (reconciliation.rs `emit_tenant_meta_spec_set_updated`, merge_processor.rs `emit_queue_updated`, api/admin.rs `admin_seed`) pass `Destination::Broadcast`, so the guard changes no live emission; the Broadcast carve-out is preserved. Test `emit_scoped_event_rejects_scopeless_non_broadcast_message` drives the real emitter through both rejected shapes (Workspace and Agent destination with `workspace_id: None`) using a counting `MessageRepository` wrapper wired via the new `mem::test_state_with_messages` helper, asserts Err + an ERROR-level captured log record (real `tracing` capture layer, not a mocked logger), asserts store-count 0 and empty broadcast + dispatch channels, and carries two controls (Broadcast passes and is broadcast-not-stored; scoped Workspace passes, stores exactly once, is broadcast). Kill-strength: removing the guard makes `result.is_err()` fail and store-count 0 fail.

2. **Mem store contract (AC 2).** `MemMessageRepository::store` returns `Err` on `workspace_id: None` before inserting — the same constraint SQLite/PostgreSQL `message_to_new_row` enforce, closing the mem-port-contract divergence on the wired adapter. Test `mem_store_rejects_scopeless_message` mirrors the SQLite contract test (Broadcast rejected, scopeless non-Broadcast rejected and absent from `find_by_id`, properly-scoped message stores — happy path not over-blocked).
