4. **Origin table** — new `AuthenticatedAgent.auth_mechanism: AuthMechanism` is a non-optional field set at every extractor construction site (compilation enforces completeness): global token → `GlobalToken`/Server; API key → `ApiKey`/User(user_id from key lookup); Keycloak/OIDC RS256 `validate_jwt` → `UserJwt`/User; per-agent token (UUID legacy or agent JWT) → `AgentToken`/Agent; federation → `FederatedJwt`/Agent; impersonation (`resolve_impersonation_auth`) → `Impersonation`/User(target). 5. **Rule-1 tenant isolation** — both the REST handler and the mirrored MCP `handle_message_send` load the target agent's workspace record on every `Destination::Agent(id)` send and compare its `tenant_id` with the caller's verified tenant (the message's `tenant_id` is built from `auth.tenant_id`, so the comparison is against the message's tenant exactly).
