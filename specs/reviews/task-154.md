- Document timestamps: `SearchDocument.updated_at` is stamped at the three entity-create index sites (tasks/MRs/agents use the entity's own update time) and defaults to index time elsewhere; SQLite persists it under a reserved `updated_at` metadata key (FTS5 virtual tables cannot be ALTERed — schema stays the specced §Index Schema DDL verbatim), PG adds a real `updated_at` column with an idempotent `ADD COLUMN IF NOT EXISTS` for pre-existing tables. Both adapters strip the reserved key from results and aggregations.
