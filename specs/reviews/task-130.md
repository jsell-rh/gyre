### Findings

- [ ] **F1 (major): `gyre_list_mrs` with no `repository_id` silently bypasses the §1 scope gate — cross-tenant MR read.** `validate_tool_scope`'s `gyre_list_mrs` arm returns `Ok(())` when the arg is absent on the false assumption "handler rejects the missing field" (mcp.rs:720-726); `handle_list_mrs` treats `repository_id` as optional and falls back to `state.merge_requests.list()` — the shared, unfiltered store (mcp.rs:1722-1726). A worker token scoped to one repo calling `tools/call gyre_list_mrs {}` receives every MR across all workspaces/tenants. Violates "MCP server validates scope on every tool call" / "Scope mismatch returns clear error (not silent allow)" and the coverage row's claim that list_mrs is worker-gated. The with-arg path is correctly denied; the no-arg shape is untested. Contrast: `gyre_create_mr`'s handler genuinely rejects the missing field (`require_str`), so the identical fallthrough there is safe — only list_mrs rests on the false assumption. Evidence: `review-evidence/finding-f1-list-mrs-noarg-bypass.txt`.
- [ ] **F2 (moderate): the worker-tool scope arm never binds the target agent to the token's scope.** mcp.rs:707-710 (`gyre_agent_heartbeat | gyre_agent_complete | gyre_record_activity => check_repo_write_scope(auth, None, …)`) only checks the caller's own scope possession, never the `agent_id` argument the tools act on. `gyre_agent_complete` is separately protected (identity check at mcp_handler:3637), but `gyre_agent_heartbeat` (mcp.rs:1879-1896) has no identity or target check anywhere: a worker token can heartbeat ANY agent in any repo/workspace/tenant, updating a foreign agent's `last_seen` and defeating cross-tenant stale-agent reaping (stale_agents.rs restarts orchestrators only when heartbeats go stale). `gyre_record_activity` accepts a caller-chosen `agent_id` in its telemetry payload (routing is caller-confined; low severity). The arm is self-referential for these tools — any worker satisfies it regardless of target. Evidence: `review-evidence/finding-f2-worker-tools-target-unbound.txt`.
